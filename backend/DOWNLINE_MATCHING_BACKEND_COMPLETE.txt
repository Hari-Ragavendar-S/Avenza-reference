============================================================
🔄 HOW IT WORKS
============================================================

FLOW:
1. User makes binary match (left + right volumes match)
2. System awards binary matching bonus to that user
3. System triggers downline_matching bonus distribution
4. For EACH ancestor up to root:
   a. Get ancestor's LOWEST active package
   b. Calculate: bonus % × matched amount
   c. If > $220: User gets $220, Admin gets excess
   d. If ≤ $220: User gets calculated amount
   e. Credit Income Wallet
   f. Record transaction
5. All bonuses distributed instantly!

EXAMPLE:
User A (downline) matches $5,000

Upline Chain:
- User B: $50 package → 5% → $250 calc → Gets $220, Admin $30
- User C: $1K package → 8% → $400 calc → Gets $220, Admin $180
- User D: $300 package → 7% → $350 calc → Gets $220, Admin $130
- ... continues to root
