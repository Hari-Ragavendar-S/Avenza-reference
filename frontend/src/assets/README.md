# AVENZA Assets

## Logo Placement

Please place the official AVENZA logo in this folder as:
- `avenza-logo.png`

The logo should be a gold wing-style logo as provided.

## Logo Usage

The logo is used in:
- Header navigation
- Footer
- Loading screen
- Mobile menu

Current implementation uses a text-based placeholder "AVENZA" with gold gradient styling that matches the brand colors.
