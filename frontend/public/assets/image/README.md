# AVENZA Logo

Place your logo file here as:
- **image.png**

The logo will be displayed in:
- Header (height: 40px on desktop, 32px on mobile)
- Footer (height: 48px)
- Loading Screen (height: 80px)

## Recommended Specifications:
- Format: PNG with transparent background
- Dimensions: At least 200px height for best quality
- Aspect ratio: Maintain original proportions
- Colors: Gold/premium colors that match AVENZA branding

The image will automatically scale and maintain aspect ratio across all screen sizes.
